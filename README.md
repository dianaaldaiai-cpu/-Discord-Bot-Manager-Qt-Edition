# 🤖 Discord Bot Manager — Qt Edition          # ملاحضه بسيطه لازم تزور موقع  https://kerdiscord123.vercel.app وشكرا و اكتب اسمك و رح يولدلك مفتاح 

نفس التطبيق، لكن بمكتبة حديثة: **PySide6 (Qt6)** بدل customtkinter، مع **qasync**
لدمج asyncio مباشرة داخل event loop تبع Qt (بدون Thread منفصل) — وهذا يحل غالباً
مشكلة "ما يتصل أبداً" لأنه ما يصير تعارض بين event loop تبع tkinter وevent loop تبع البوت.

## 🔑 جديد: نظام تفعيل بمفتاح (Activation)
أول ما تفتح التطبيق تطلع نافذة تفعيل تطلب **اسم/معرّف** + **مفتاح تفعيل**. المفتاح
تولّده من ملف **key_generator.html** المرفق (صفحة ويب مستقلة، تفتحها بأي متصفح — ما
تحتاج سيرفر أو إنترنت). تدخل اسم العميل، تضغط "توليد المفتاح"، وتعطيه الاسم + المفتاح.
بعد أول تفعيل ناجح التطبيق يحفظه محلياً (QSettings) وما يطلبه مرة ثانية.

**كيف تشتغل الخوارزمية:** `main.py` وصفحة `key_generator.html` يستخدمون نفس معادلة
HMAC-SHA256 مع نفس "السر" (`LICENSE_SECRET` بالبايثون = `SECRET` بالـ JS)، فالمفتاح
الناتج من الصفحة يطابق بالضبط اللي يتحقق منه التطبيق — بدون أي اتصال إنترنت أو سيرفر.

> ⚠️ **مهم جداً قبل التوزيع:**
> 1. غيّر قيمة السر بالملفين معاً لقيمة سرية خاصة فيك (نفس النص بالضبط بالمكانين):
>    - `main.py`: المتغير `LICENSE_SECRET`
>    - `key_generator.html`: المتغير `SECRET` بالسكريبت
> 2. **هذا النظام حماية بسيطة وليس مانع قرصنة حقيقي.** بما إن صفحة `key_generator.html`
>    صفحة HTML ثابتة تعمل بالكامل بالمتصفح، أي شخص يفتح "عرض المصدر" يقدر يشوف السر
>    ويولّد مفاتيح بنفسه. هذا كافي لمنع الاستخدام العرضي غير المصرح به أو لتتبّع من
>    وزّعت له نسخة، لكن لو تبي حماية فعلية ضد قرصنة متعمدة، لازم التوليد والتحقق
>    يصير على سيرفر خلفي (Backend) لا يشوفه المستخدم — قولّي لو تبي أساعدك تبنيه.
> 3. لا تشارك ملف `key_generator.html` نفسه مع المستخدمين النهائيين — خله عندك أنت بس،
>    وأرسلهم المفتاح الجاهز فقط.

## 🎨 جديد: إعدادات المظهر
اضغط زر **⚙️ المظهر** أعلى النافذة لفتح لوحة الإعدادات:
- وضع **فاتح ☀️** أو **داكن 🌙**.
- **أي لون بالعالم** كلون رئيسي للتطبيق (زر "اختر لون 🎨" يفتح منتقي ألوان كامل)، بالإضافة
  لمجموعة ألوان جاهزة سريعة.
- الاختيار يُحفظ تلقائياً (عبر QSettings) ويُستخدم من نفسه بالمرة الجاية.

## 🔊 جديد: إصلاح مشكلة عدم الانضمام للرومات الصوتية
كانت المشكلة الأكثر شيوعاً هي أن مكتبة **Opus** (المطلوبة إلزامياً من discord.py
لأي اتصال صوتي) ما كانت تُحمَّل تلقائياً، فيفشل الانضمام بصمت أو برسالة غير واضحة.
الآن التطبيق:
1. يحاول تحميل Opus تلقائياً عند بدء التشغيل (يجرب عدة أسماء شائعة حسب نظام التشغيل).
2. يتحقق من صلاحية **Connect** الخاصة بالبوت في الروم قبل المحاولة، ويعطيك رسالة واضحة
   إذا كانت الصلاحية ناقصة.
3. يعطي مهلة زمنية (20 ثانية) بدل التعليق للأبد، ويطبع سبب الفشل الحقيقي بالسجل
   (Timeout / صلاحيات / Opus غير محمّل / أي خطأ آخر).

إذا استمرت المشكلة بعد كل هذا، الأغلب أنك على **Linux** وتحتاج تثبيت المكتبة يدوياً:
```bash
sudo apt install libopus0
```

## 🎮 جديد: الأنشطة (Activities) داخل الروم الصوتي
ديسكورد يسمح للبوتات بإنشاء رابط دعوة خاص يشغّل نشاط رسمي (Watch Together, Poker Night,
Chess in the Park...) مباشرة داخل روم صوتي — بالضبط زر "Activities" اللي شايفه بالتطبيق
الرسمي. من قسم **🎮 الأنشطة (Activities)** اختر الروم والنشاط، وبيرجعلك رابط تفتحه لتشغيله.

> ⚠️ ملاحظة مهمة: هذا **غير** نفس شيء بناء "تطبيق Activity" خاص بك من الصفر (مثل Watch
> Together نفسه) — بناء نشاط خاص يتطلب مشروع ويب منفصل بالكامل (React + Discord Embedded
> App SDK) مستضاف أونلاين بـ HTTPS، وهذا خارج نطاق تطبيق سطح المكتب هذا. لو حبيت نبنيه
> كمشروع منفصل قولّي.

## 📢 عن طلب "السبام"
تعمّدت عدم إضافة أي ميزة "سبام منشن متكرر" أو تنبيه تلقائي متكرر لكل الرومات — هذا النوع
من السلوك يخالف سياسة ديسكورد ويؤدي لحظر البوت فوراً (يُصنَّف كـ raid/nuke bot). بدالها
ضفت قسم **📢 إعلانات لمرة واحدة**: يرسل نفس الرسالة مرة وحدة فقط لكل القنوات أو لكل من
هو حالياً بروم صوتي — مفيد للإعلانات الرسمية بدون تكرار مزعج.

## 🎫 جديد: نظام التكتات (Tickets) — قابل للتخصيص بالكامل
قسم **🎫 نظام التكتات** فيه زرين بس، بالضبط زي ما طلبت:

1. **تخصيص نظام التكتات ⚙️** — نافذة توضح كل الإعدادات وتقدر تعدّلها:
   - عنوان ووصف لوحة التكتات (اللي تظهر كـ Embed)
   - نص وإيموجي الزر
   - القسم (Category) اللي تُنشأ فيه قنوات التكتات
   - رتبة الدعم اللي تشوف كل تكت وتنمنشن تلقائياً
   - رسالة الترحيب جوا كل تكت (تقدر تستخدم `{mention}` عشان تمنشن صاحب التكت)
   - اللون ياخذه من نفس لون الثيم اللي مختاره من إعدادات المظهر ⚙️
2. **إرسال لوحة التكتات 📨** — لما تخلص التخصيص، هذا هو الأمر الوحيد اللي تحتاجه: تختار
   القناة وتضغط تنفيذ، وتنبعث اللوحة فيها بزر "فتح تذكرة".

**كيف تشتغل من طرف الأعضاء:** أي عضو يضغط الزر → تنفتح له قناة خاصة (يشوفها بس هو
+ رتبة الدعم + البوت) فيها رسالة ترحيب وزر "إغلاق التذكرة 🔒". لما يُضغط زر الإغلاق
تُحذف القناة تلقائياً بعد 5 ثواني. الأزرار **دائمة** (Persistent Views) — تشتغل حتى
لو أغلقت التطبيق وشغّلته مرة ثانية، ما تحتاج تعيد إرسال اللوحة.

- 🌐 عام (4): معلومات السيرفر، عدد المتصلين، إشغال الرومات الصوتية، تغيير حالة البوت
- 💬 الرسائل (6): إرسال، منشن everyone/here/مخصص، رسالة خاصة للجميع، حذف رسائل
- 🔊 الصوت (9): انضمام/مغادرة، كتم/فك كتم/صم/فك صم الكل، فصل الكل، تشغيل/إيقاف صوت
- 🛡️ الأعضاء والإدارة (6): طرد، حظر، فك حظر، إضافة/إزالة رتبة، تغيير اسم البوت
- 📁 القنوات (8): إنشاء نصية/صوتية، حذف، موضوع، Slowmode، قفل/فتح، تصنيف جديد
- 🎮 الأنشطة (4): تشغيل Activity، كتم/صم البوت لنفسه، نقل عضو بين الرومات
- 📢 إعلانات لمرة واحدة (2): تنبيه من بالرومات الصوتية، بث لكل القنوات
- 🛡️ إدارة متقدمة (11): تايم اوت، إلغاؤه، طرد/حظر جماعي (بتأكيد)، رتب متعددة، معلومات عضو، محظورين، تقليم خاملين
- 📊 تقارير (5): كل الرتب، بدون رتبة، البوتات، Audit Log، مستوى البوست
- 🔗 الدعوات (2): إنشاء رابط دعوة، عرض الروابط الفعالة
- 🏷️ السيرفر والإيموجي (3): عرض/حذف إيموجي، تغيير اسم السيرفر
- 🎫 نظام التكتات (2): تخصيص نظام التكتات، إرسال لوحة التكتات

**المجموع: 62 أمر.**


## 1. التثبيت
```bash
pip install -r requirements.txt
```
لتشغيل الصوت تحتاج **ffmpeg** مثبت على جهازك ومضاف للـ PATH.

## 2. لماذا ما كان يتصل بالنسخة القديمة؟ (وكيف تتجنبها هنا)
أشيع الأسباب:
1. **التوكن خطأ أو منتهي** — تأكد إنك نسخته كامل من Discord Developer Portal (Bot → Reset Token).
2. **Privileged Intents غير مفعّلة** — لازم تفعّل من نفس الصفحة (Bot):
   - SERVER MEMBERS INTENT
   - PRESENCE INTENT
   - MESSAGE CONTENT INTENT
   لو ما فعّلتها، البوت يرفض الاتصال برسالة `PrivilegedIntentsRequired` — هذه النسخة توضحلك
   الخطأ بالضبط برسالة منبثقة + بالسجل بالأسفل.
3. **مشكلة إنترنت/فايروول** يمنع الاتصال بسيرفرات Discord (gateway).
4. **استخدام توكن يوزر عادي بدل بوت** — غير مدعوم إطلاقاً ومخالف لسياسة ديسكورد.

هذه النسخة تطبع أي خطأ حقيقي (بما فيه الـ traceback الكامل) في سجل النشاط، فلو ما اتصل
شوف السجل وارسللي النص وبساعدك أشخّص السبب بالضبط.

## 3. التشغيل
```bash
python main.py
```
1. الصق التوكن واضغط **اتصال 🚀** (بتشوف أنيميشن تحميل دوّار).
2. عند النجاح يظهر "🟢 متصل بنجاح" بأنيميشن fade-in، وتقدر تختار السيرفر.
3. استخدم الأزرار المصنّفة (11 قسم) — 62 أمر بالمجموع.
4. تابع سجل النشاط على اليمين لمعرفة نتيجة كل عملية أو أي خطأ.
